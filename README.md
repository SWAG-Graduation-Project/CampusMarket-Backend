## ✨ 주요 기능 간략 소개

### 내 상점 페이지
내 상점, 물건 판매하기, 사진 배경 자동 제거하기, 가격 입력 후 LLM이 작성한 상품 소개글로 판매하기, 거래 완료 변경

### 메인 페이지
판매자 판매 상품 리스트(리스트로 보기, 테이블로 보기), 상품 상세

### 채팅 페이지
판매/구매 채팅 분류, 비대면 만남 제안 및 수락(각자의 사물함 위치 공개), 대면 만남 제안 및 수락(개인정보 지워진 각자의 시간표 공개), 신고 및 관리자 이메일 전송

### 내 정보 페이지
정보 수정, 시간표 AI 파싱, 시간표 수정 및 추가, 사물함 선택
